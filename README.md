# 2D Playground

A browser-based 2D graphics playground using HTML5 Canvas and JavaScript.

**Live Demo:** [2D Playground on GitHub Pages](https://expdev-mul.github.io/2D-Playground/)

## Features

- Interactive 2D canvas rendering
- Real-time animation loop
- Keyboard and mouse input handling
- Clean, extendable structure for prototypes

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/2D-Playground.git
   ```
2. Open `index.html` in your web browser.

## Notes

No external libraries are used. This is a standalone front-end playground for experimenting with 2D graphics and interaction logic.
